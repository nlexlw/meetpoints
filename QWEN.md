# MeetPoint Project Context

## Project Overview
MeetPoint is a hackathon MVP for networking at events, conferences, and hackathons.

## Tech Stack
- **Backend**: FastAPI, SQLite, SQLAlchemy, Pydantic
- **Frontend**: React, Vite, JavaScript, CSS

## Main Product Flow
1. Organizer creates event and gets shareable link/QR
2. Participant joins event by following the link
3. Participant creates mini-profile with tags and contact info
4. Users see recommendations based on shared interests
5. Users can send meet requests to each other
6. Contact information is only revealed after a request is accepted

## Development Rules
- Keep it simple
- Do not overengineer
- Do not add JWT/PostgreSQL/Docker unless explicitly asked
- Make small, understandable changes
- Do not delete files
- Do not commit or push without permission
